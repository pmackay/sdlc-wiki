## One-line identity

An open-source, **model-agnostic** AI coding agent — terminal-first (TUI), also a desktop app and IDE extension — from the SST/Anomaly team, distinguished by a native plugin+hook system and support for many model providers.

## Interaction surface

Primary/native = **terminal TUI**. Also: a **desktop app** (beta) and an **IDE extension**; sessions shareable via web links. Native surface is the terminal.

## Model access

**Model-agnostic / multi-provider**: Anthropic Claude, OpenAI, Google Gemini, AWS Bedrock, Azure OpenAI, Groq, OpenRouter, and others via API keys. Also **OpenCode Zen**, a curated set of tested/hosted models. (Contrast with Claude Code, which is Anthropic-models-only.)

## Execution primitives

- **Sub-agents/agents** — YES. Built-in agents **build** (full tool access) and **plan** (read-only), plus General, Explore (read-only), and a Scout research agent; background subagents supported.
- **MCP** — YES, MCP servers supported.
- **Hooks** — YES, a native plugin hook system (e.g. `tool.execute.before` / `tool.execute.after` / `session.idle`) that can intercept/block/modify tool calls.
- **Custom slash-commands** — YES.
- **Skill/command format** — **AGENTS.md** for project config; configurable "skills," rules, and custom tools.
- **Permissions/approval** — YES, a permissions & policies framework (e.g. the plan agent set to "ask" before edits/bash).
- **Plan mode** — YES, a "Plan" agent/mode for non-destructive analysis vs "Build" mode.
- **Session persistence/resume** — YES, session management with undo/redo and shareable links.
- **Memory/context files** — YES, AGENTS.md project configuration.

## Extensibility / distribution

Open-source (MIT). Ships **plugins** and an **SDK**. Install via curl script, npm/Bun/pnpm/Yarn, Homebrew, Arch, Windows (Chocolatey/Scoop/Docker), Mise. A community registry ("awesome-opencode") of plugins/themes/agents exists.

## Distinctive

Provider-neutral, terminal-first agent with a robust native plugin+hook system and multiple surfaces (TUI/desktop/IDE). "OpenCode Zen" curated model marketplace is a notable differentiator. Batteries-included primitive set (agents, MCP, hooks, plan mode, permissions), unlike pi's minimal core.

## Wiki cross-references

- Spawned by runtimes: listed as a provider by Sandcastle (Claude Code/Codex/pi/Cursor/OpenCode/Copilot).
- Officially a target of cross-harness frameworks (e.g. Superpowers names OpenCode).
- Patterns it provides as primitives: fresh-context-subagents (build/plan/explore/scout agents), edit-guardrails (permissions + plan-ask + hooks), session-handoff (session mgmt/resume/undo), context-engineering (AGENTS.md + skills + MCP).
