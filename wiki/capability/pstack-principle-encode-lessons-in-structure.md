# principle-encode-lessons-in-structure

**Meta principle.** Encode the rule as a lint, metadata flag, runtime check, or script instead of more text.

Applies when you catch yourself writing the same instruction a second time, or notice a recurring correction. The meta-principle that governs the framework's own growth, and it is wired in as a gate: [[pstack-reflect]] runs a dedicated structural-enforcement check that *demotes* any accepted learning better served by a lint rule from Accepted to Backlog, so pstack resists the prose-accretion failure mode most skill libraries drift into.
