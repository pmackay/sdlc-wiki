# principle-experience-first

**Core principle.** Choose user delight over implementation convenience; ship fewer polished features over more rough ones.

Applies when product, UX, or feature-scope tradeoffs come up. The only principle in the set aimed at product judgment rather than code shape, and the one that most directly encodes the framework's thesis that throughput without quality is not a goal.
