# principle-foundational-thinking

**Core principle.** Get the data structures right so downstream code becomes obvious.

Applies before writing logic: choosing core types and data structures, sequencing scaffold-vs-feature work, asking what concurrent actors share. [[pstack-architect]] is this principle made into a workflow, and its synthesized sketch can ship as its own commit in the "scaffold first" mode named here.
