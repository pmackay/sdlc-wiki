# Artifact: Product docs (mission / roadmap / tech-stack)

A lightweight trio of durable product-direction documents in [[agent-os]]'s `agent-os/product/` folder:

- **`mission.md`** — product vision, target users, core problems solved.
- **`roadmap.md`** — a phased development plan (MVP must-haves vs post-launch phases).
- **`tech-stack.md`** — the project's technical stack choices (may reference a global tech-stack standard).

Authored once, up front, by [[agent-os-plan-product]] through a one-question-at-a-time interview, and read as standing context by [[agent-os-shape-spec]] when planning each feature. Deliberately lightweight — a standing *product-direction anchor*, not a heavyweight PRD.
